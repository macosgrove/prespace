---
description: How to start and stop the local development server
---

### Starting the Server
To start the interactive 3D graph development server:
1. Open your terminal in the `prespace` directory.
2. Run the following command:
```bash
npm run dev
```
3. Open your browser to the URL displayed (usually `http://localhost:5173/`).

### Stopping the Server
To stop the server:
1. Go to the terminal window where the server is running.
2. Press **`Ctrl + C`** on your keyboard.

### Running Automated Tests
To run the automated logic tests:
```bash
npm test
```
